10. MCP tool schema discovery

Do not hard-code the tool input form where possible.

Use MCP's tool discovery mechanism.

The backend should:

    Connect to MCP server.

    List available tools.

    Read each tool's name.

    Read description.

    Read input schema.

    Dynamically send this information to the frontend.

    Generate the appropriate form.

    Send user input back to the backend.

    Call the selected MCP tool.

    Return the result to the browser.

This should work with different MCP servers rather than being hard-coded exclusively for one server.

12. MCP safety

Implement strict safety controls.

Never allow an MCP server to access arbitrary files or execute arbitrary commands without explicit configuration.

Filesystem access must use an allowlisted directory.

Do not expose arbitrary shell execution to the browser.

Never send environment variables/secrets back to the frontend.

Never display API keys in the UI after they are saved.

Do not store secrets in localStorage.

Use environment variables on the backend.
